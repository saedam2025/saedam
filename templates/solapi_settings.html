발송 규칙
계약대상자에게 휴대폰번호가 있으면 알림톡으로 계약 링크를 발송하고 인증번호는 SMS로 보냅니다. 휴대폰번호 없이 이메일만 있으면 기존 이메일 링크와 이메일 인증을 사용합니다.

알림톡 템플릿 변수
승인 템플릿에는 계약자 이름 변수 #{이름}과 계약 링크 변수 #{url}을 사용하세요. 웹링크 버튼명은 전자계약서보기이며 모바일·PC 링크에는 모두 https://#{url}을 지정합니다. 시스템이 #{url}에 https://를 제외한 주소를 넣습니다. 본문·강조문구·버튼은 솔라피에 승인된 템플릿을 그대로 사용합니다. 계약 등록과 발송은 works.saedam.org에서 진행해 주세요. 알림톡 실패 시에는 솔라피의 문자 대체발송 설정이 적용됩니다.

설문조사 알림톡
학교관리 > 설문조사의 기본 발송방법은 카카오 알림톡입니다. 위 [카카오 알림톡 템플릿]의 설문조사 칸으로 발송하며, 템플릿의 #{변수}는 설문 화면에서 자동으로 채워집니다 (예: #{이름}=수신자 이름, #{제목}·#{설문명}=설문 제목, #{기관명}=발신 기관명, #{url}·#{링크}=수신자별 응답 주소, #{기간}·#{마감일}=응답 기간). 버튼 주소가 https://#{url} 형식이면 https://를 뺀 주소를 넣습니다. 알림톡이 실패하면 설문 화면의 문자 내용으로 대체발송할 수 있습니다.

학부모 안내 알림톡
학교지원 > 학부모·강사 통합지원 > 학부모 안내 > 링크 발송에서 카카오 알림톡을 고르면 위 [카카오 알림톡 템플릿]의 학부모 안내 링크 칸으로 보냅니다. 승인 템플릿에는 학교 이름 변수와 안내 주소 변수 두 개만 쓰세요(기본 이름은 #{학교명}과 #{url}). 솔라피에 다른 이름(예: #{school_name})으로 신청했다면 카드의 템플릿 변수 이름을 그 이름으로 바꿔 주세요. 이름에 school·학교가 들어 있으면 따로 설정하지 않아도 학교 이름으로 알아봅니다. 웹링크 버튼 주소가 https://#{url} 형식이면 https://를 뺀 주소를 넣습니다. 알림톡이 실패하면 발송 화면에서 정한 문자 내용으로 대체발송할 수 있습니다.

추가한 템플릿
[+ 템플릿 추가]로 적어 둔 템플릿은 이름과 ID가 저장되고, 새 기능이 알림톡을 보낼 때 이름으로 불러다 씁니다(채널 ID를 비우면 설문조사 채널). 아직 연결된 기능은 위 세 가지(인증전자계약·설문조사·학부모 안내 링크)입니다.

설문조사 문자
문자(LMS)를 선택하면 알림톡 템플릿 없이 API KEY · API SECRET · 발신번호만으로 URL 문자를 보냅니다. 본문이 EUC-KR 90바이트를 넘으면 자동으로 LMS(장문)로 전환되며, 이때 제목에는 위의 문자 발신 기관명이 들어갑니다. 수신자에게 전달되는 설문 주소는 공개 링크 기본 주소 + /survey/r/… 형태입니다.
